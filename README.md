# NexusFlow

NexusFlow is a visual IoT telemetry and rule engine. It allows users to build sensor-data workflows through a drag-and-drop canvas.

## Technology Stack

- React and React Flow
- Node.js and Express
- MongoDB Time-Series Collections
- WebSockets
- RxJS

## Week 1 Goals

- Set up the React and Node.js applications
- Integrate the React Flow canvas
- Design MongoDB Time-Series telemetry storage
- Create the telemetry ingestion API
